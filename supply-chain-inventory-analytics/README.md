# 📦 Supply Chain & Inventory Analytics Dashboard

## 📊 Project Overview

This project is an end-to-end **Supply Chain & Inventory Analytics** project built to analyze inventory levels, product sales, supplier performance, delivery time, revenue, and profitability.

The project uses a dataset containing **15,000 supply chain records** and transforms raw operational data into meaningful business insights through data cleaning, analysis, calculated measures, and an interactive Power BI dashboard.

The main purpose of this project is to help businesses answer questions such as:

- How much revenue and profit are being generated?
- Which products are selling the most?
- Which products require inventory attention?
- Which suppliers have higher delivery times?
- Which categories generate higher profit?
- How does delivery performance vary month by month?
- How can inventory management be improved?


---

# 🎯 Business Problem

Supply chain operations generate a large amount of data related to products, inventory, suppliers, sales, purchasing costs, selling prices, and deliveries.

However, raw data alone does not provide an easy way for decision-makers to identify important operational problems.

Some of the key challenges addressed in this project were:

### 1. Inventory Management
Businesses need to maintain enough stock to satisfy customer demand while avoiding unnecessary inventory.

If inventory falls below the reorder level, the business may face stock shortages and potentially lose sales.

### 2. Supplier Performance
Different suppliers can have different delivery times.

Longer shipping times can affect inventory availability and make supply chain planning more difficult.

### 3. Product Performance
Businesses need to identify:

- Fast-moving products
- Slow-moving products
- High-revenue products
- High-profit products
- Products requiring inventory attention

### 4. Profitability Analysis
High sales do not necessarily mean high profit.

A product may generate significant revenue but have a lower profit margin because of its purchase cost.

### 5. Delivery Performance
Delivery time needs to be monitored to understand whether supply chain operations are consistent across different months and suppliers.

# 🗂️ Dataset

The dataset contains **15,000 records** with the following major fields:

| Column | Description |
|---|---|
| Product_ID | Unique product identifier |
| Product_Name | Name of the product |
| Category | Product category |
| Supplier_Name | Supplier associated with the product |
| Order_Date | Date of the order |
| Delivery_Date | Date of delivery |
| Stock_Quantity | Current available inventory |
| Reorder_Level | Inventory level at which replenishment is required |
| Units_Sold | Number of units sold |
| Purchase_Cost | Cost of purchasing the product |
| Selling_Price | Selling price of the product |
| Warehouse_Location | Location of the warehouse |
| Shipping_Time_Days | Number of days taken for shipping |

---

# 🧹 Data Cleaning

Before performing the analysis, the dataset was checked and prepared for analysis.

The main data preparation steps included:

- Checking for duplicate records
- Checking missing values
- Formatting date columns
- Checking numerical columns
- Checking stock and reorder-level values
- Creating calculated fields required for business analysis
- Validating sales, revenue, profit, inventory, and shipping metrics

This ensured that the data could be used reliably for further analysis and dashboard creation.
